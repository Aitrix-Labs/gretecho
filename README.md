# Gretecho website

Corporate fintech landing page for [gretecho.com](https://www.gretecho.com), built with Vite + React + TypeScript.

## Run

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — local development server
- `npm run build` — production build
- `npm run preview` — preview production build

## Structure

- `src/components` — Navbar, Hero, About, Stats, Solutions, News, Verticals, Footer
- `src/data/content.ts` — page content and metrics
- `src/index.css` — global styles and layout
